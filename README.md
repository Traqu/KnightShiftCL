# KnightShiftCL

Community launcher for **KnightShift / Polanie II**, with game fixes, display settings and multiplayer setup.

[**Download KnightShiftLauncher.exe**](https://github.com/Traqu/KnightShiftCL/releases/download/v1.0.0/KnightShiftLauncher.exe)

1. Download and run the EXE. Windows 10/11; no additional runtime installation is needed.
2. The launcher finds your game automatically. Use **Change folder...** if needed.
3. Choose your settings and click **Play**.

- **Community fixes:** fix the game running too fast and enable Improved camera.
- **Display:** choose resolution, refresh rate, fullscreen and Skip intro.
- **Fanmade Gold Edition:** download and install version 2.9.0 in Polish or English, or install a local ZIP.
- **Multiplayer:** enter your player name and set up Radmin VPN for the Polanie MP network.
- **Settings:** CD-key, Windows startup, Forest/Dark themes, UI scale and interface sounds.

Close the game before applying changes. Original files and settings are backed up in the game's `fix` folder. Keep that folder to restore changes. To remove a community fix, clear its checkbox and click **Apply fixes**.

The launcher modifies your installed game; it does not include or distribute the game's executable.
